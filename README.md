GitHub Project: eDonish Phishing Demo
Description:
This project demonstrates a security vulnerability in the eDonish teacher portal (used for grading students) by replicating its login page as a phishing simulation. The goal is to raise awareness about weak authentication practices and potential risks of credential theft in educational platforms.

⚠️ Disclaimer:

For educational purposes only.

Highlights the need for better security (like 2FA or CSRF protection).

Not intended for malicious use.

Technologies: HTML, CSS, JavaScript (frontend clone).
Usage:
1. Fork this project to your github
2. Authorise in netlify or any other hosting servise
3. Deploy your forked project on the netlify
   
🔗 Live Demo: https://edonish.netlify.app | Report Vulnerability: https://edonish.com
